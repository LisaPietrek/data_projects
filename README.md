# Data Projects Portfolio

This repository contains selected projects focused on analysing data - cleaning, structuring, and analyzing real-world datasets. The analysis is done with or without machine learning.

## data_analysis
Data cleaning and preprocessing projects + exploratory data analysis and visualization  

## machine_learning

This folder contains small machine learning projects based on concepts I learned during studies and from books or online courses.
Each project explores different models or techniques to strengthen my practical understanding of machine learning.


### homl3_exercises

This folder contains exercises from the book:
“Hands-On Machine Learning with Scikit-Learn, Keras, and TensorFlow" by Aurélien Géron.


## Tools
- Kaggle (to import large data sets)
- Python (Pandas, Numpy, Matplotlib, Seaborn, Scikit-Learn)
- Jupyter Notebook
