# Data Projects Portfolio

This repository contains selected projects focused on analysing data - cleaning, structuring, and analyzing real-world datasets.

## Structure
- `data_analysis/` – Data cleaning and preprocessing projects + exploratory data analysis and visualization  

Projects using the same dataset are grouped accordingly.

## Tools
- Kaggle (to import large data sets)
- Python (Pandas, Numpy, Matplotlib, Seaborn)
- Jupyter Notebook
